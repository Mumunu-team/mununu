# Clock-gating interlock — sound kernel synthesis + whole-system verification

The third example in the mununu control-kernel corpus (after the arbiter in
`../agentic_rtl_loop/` and the flow controller in `../handshake_flow/`). Same
loop, a different control pattern: a **safety interlock**. The gated datapath is
hand/LLM-written SystemVerilog; the **clock-gating kernel is synthesized
correct-by-construction** and mununu **verifies the whole assembled system**.

The interlock — *never gate the clock while the domain is doing work* — is a
one-line invariant that a single missed corner turns into silent data corruption.
It is exactly the kind of control edge LLM-written RTL drops.

## The loop

```
requirement.md  ──prompt.md──▶  clock_gate.tlsf  ──mununu synth──▶  clock_gate.sv
   (English)        (LLM)          (spec)          (sound GR(1))    (correct-by-construction)
                                                                        │
       gated_domain.sv (LLM-authored datapath, with SVA) ──assemble──▶ system.sv
                                                                        │
                                                            mununu verify (sv2v+yosys+btormc)
                                                                        ▼
                          never-gate-while-active ✓   idle-discharge ✓   eager-sleep ✓
```

## The pieces

| File | Role | Who writes it |
|---|---|---|
| `requirement.md` | the plain-English interlock requirement | the designer / upstream agent |
| `prompt.md` | the reusable NL → TLSF prompt | the loop |
| `clock_gate.tlsf` | the control-kernel spec | the LLM, via `prompt.md` |
| `gated_domain.sv` | the clocked datapath (freezes while gated), with interlock SVA | LLM-authored datapath |
| `system.sv` | the top: domain + kernel + verification monitors | assembly |
| `clock_gate.sv` | the **synthesized** kernel | **mununu** (generated by `run.sh`) |
| `run.sh` / `verify.sh` | synthesize → assemble → verify | the loop |

## Run it

```bash
./run.sh          # needs `mununu` on PATH + the mununu-sva docker image
```

## What is verified

**Interlock + assume-guarantee discharge — k-induction (sound, unbounded):**

- `bad_interlock` — never gate the clock while the domain is active.
  **(the headline safety property)** The `gated_domain`'s own assertion
  (`a_no_work_while_gated`) is the dual view: the domain is never mid-work while
  gated — guaranteed precisely *because* the kernel respects the interlock.
- `bad_assume_idle` — the domain **discharges** the kernel's `G F !activity`
  assumption (it always returns to idle). The compositional payoff: the kernel is
  correct *under* the assumption that the domain eventually idles, and the
  concrete domain *supplies* that.

**Liveness — bounded model checking to depth 100:**

- `bad_sleep_stall` — **eager sleep honor**: once the domain is idle, the kernel
  never leaves a `sleep_req` waiting more than one cycle. Verified by bounded
  model checking (no stall reachable within 100 cycles).

  > Honesty note. As in the flow-control example, the eager-response liveness is
  > reported as a **bounded** check, not an unbounded proof: the toolchain here
  > (sv2v/yosys) does not lift `s_eventually` for a justice-based liveness proof.
  > The interlock and discharge above are the sound, unbounded results.

## Negative control

The verification is not vacuous. Swap the synthesized kernel for a broken one that
gates whenever `sleep_req` is asserted (ignoring `activity`), and `bad_interlock`
becomes **`sat`** — the check discriminates.

## Honest scope

- A **constructed demo system**, not a finding about a real chip.
- The kernel is in the **GR(1) reactive-control fragment**; the domain is
  abstracted to a fair `activity` input, discharged by the concrete datapath.
- The **NL → TLSF leg is done by an LLM** (`prompt.md`); `clock_gate.tlsf` is an
  example output. mununu owns the synthesis and verification legs.
