# Consumer briefing — 2026-10 lever plan, open items: the ladder in `sv verify-auto`'s first-pass exact member, `CapLadder`, the fair-cycle rescue off the closure, the `circuit` order

> **Audience:** every `sv verify-auto` lane (the first-pass exact member now runs the ladder — properties that used to `Skipped` may now decide, and `decided_by` carries the stage); `btor2 verify-justice` callers (the counter class decides via the fair cycle read off the squaring closure); anyone setting `MUNUNU_BDD_VAR_ORDER`.
>
> **Related:** [`2026-10-lever-gating-ladder.md`](2026-10-lever-gating-ladder.md) (the ladder), the lever gating plan page. Policy: [`docs/policies/cross-repo-impact.md`](../policies/cross-repo-impact.md).
>
> **TL;DR:** **Verdict-semantics change on `sv verify-auto`: the first-pass exact member runs the ladder** (unrestricted ≤ 2 s → reach-restricted with a 5 s probe and a 30 s cap → unrestricted with the engine's budgets), so a property the one-shot attempt abstained on may now decide, attributed `exact-symbolic` or `exact-symbolic (reach-restricted)` in `decided_by`. The cube-skip rescue and the recoverability rescue additionally retry a `BitCap` abstention once at the 1024-bit ceiling under 60 s (`CapLadder`). The exact engine's squaring rescue gained a second read-off: a fair-EG ν (`νZ. ⋀ₖ ◇μY.((Z ∧ lₖ) ∨ ◇Y)`, the `verify-justice` formula) that is still iterating past the threshold is answered by the fair cycle read off the transitive closure (Touati–Brayton–Kurshan), so the LIVE counter class decides instead of peeling one value per iteration. `MUNUNU_BDD_VAR_ORDER=circuit` is a new opt-in order. No wire shape changed.

## What changed

- [`verify_auto.rs`](../../crates/mununu-core/src/adapter/slang/verify_auto.rs): the first-pass exact member and `rescue_skipped_via_exact` call [`exact_ladder`](../../crates/mununu-core/src/adapter/btor2/symbolic_bitblast.rs); `PropertyVerdict::decided_by` is set to the stage on an exact decision (it was `None`). The ranking rescue on an exact abstention is unchanged.
- `ExactSymbolicOptions::max_bits` (a per-request cap, clamped to 1024, threaded to the bit-blaster as `build_with_keep_bit_index_and_cap`) and `ExactSymbolicOptions::cap_ladder` (the retry; on in `rescue_skipped_via_exact` and `verify_recoverability_attributed`, off elsewhere). `CAP_LADDER_MS` = 60 000.
- `LADDER_UNBUDGETED_STAGE2_MS` = 30 000: the restricted stage's own cap when the ladder has no overall budget.
- **The fair-cycle rescue** (`Squarer::fair_cycle`, `fair_eg_shape`, the hook in `ExactModel::fixpoint`): a ν whose body is the Emerson–Lei fair-EG shape and which passes the squaring threshold (4,096 iterations) is answered off the Squarer's closure — `Core(s) = ⋀ₖ ∃t. R⁺(s,t) ∧ R⁺(t,s) ∧ lₖ(t)`, `E_C G true = Core ∨ ∃s'. R⁺(s,s') ∧ Core(s')` (Touati, Brayton, Kurshan, CAV 1991). Same arena, budget and refusal rule as the `EF` squaring; a refusal resumes the iteration where it was. **Why this and not the inner `EU`:** the first cut of this branch squared the inner `μY. ((Z ∧ l) ∨ ◇Y)` (its seed mentions the outer variable, which `pure_reach_shape` now permits, and `verify::fairness::fair_eg` spells the step as a bare `< > Y` for a `true` invariant so the detector sees it). Measured on `cucnt10ro`, the iteration charges 3,069 steps ≈ 3 · 2¹⁰: the inner `EU` converges in two steps and it is the **outer ν that peels one counter value per iteration**, so the inner squaring had nothing to replace. Both changes stay (they are correct and cost nothing); the rescue that moves the class is the closure read-off.
- `VarOrder::{Interleaved, CellMajor, Circuit}`; `MUNUNU_BDD_VAR_ORDER=circuit` keys the interleaved scheme by `circuit_visit_rank` (a DFS from the property roots through the next-state functions). Opt-in; the default is unchanged.
- `ExactSession::prepare_notes` (P5): the inputs-in-the-state trade (which inputs were lifted) and the cone width, carried into `LadderOutcome::notes`.
- `docs/verifying-rtl.md`: the l2s rung is decided by the reachability portfolio, never the exact engine (the monitor doubles the state).
- Witness extraction on a state cell wider than 128 bits: the lasso / trap representation carries a cell's value as `u128`, and the cap ladder bit-blasts cones the 192-bit cap used to refuse before any witness ran. The wall-class matrix aborted in `state_minterm` (`attempt to shift right with overflow`; a release build would have wrapped the shift into a wrong minterm). `exact_reachable_stall_lasso` / `exact_reachable_trap_path` now return `None` with a warning for such a design, `state_minterm` shifts with `checked_shr`, and `attempt` guards the extraction — the verdict stands, the counterexample is omitted. **Consumer impact:** a `violated` verdict on a design with a > 128-bit state cell carries no `counterexample`; it did not carry a *correct* one before either.

## What to update, per consumer

- **`sv verify-auto` lanes:** expect some `Skipped` → decided on the exact member; `decided_by` now names the stage for exact decisions in the main pass. A lane that must reproduce the one-shot behaviour sets `MUNUNU_EXACT_LADDER_MS` high (the first stage then runs to the engine's budgets, as before).
- **Report parsers:** no shape changes; `decided_by` values `exact-symbolic` / `exact-symbolic (reach-restricted)` now appear on main-pass verdicts.
- **Rust callers building `ExactSymbolicOptions` literally:** two new fields (`max_bits`, `cap_ladder`) or `..Default::default()`.

## Not covered here

- An ABC `pdr` member on the l2s monitor needs a BTOR2 → AIGER emitter (pono already runs `ic3bits` there); `IterationBudget → ranking` beyond the existing rescue.
- The fair-cycle rescue covers `E_C G true` (the justice verb). `E_C G q` with `q ≠ true` — `fair_af` / `fair_response`, the SVA liveness encodings — spells the step `(q ∧ ◇Y)` and still iterates; it needs the closure of the relation restricted to `q`, a second closure, not yet built. A literal that reads a primary input is refused by the transfer (no copy) and iterates; lockstep (Bloem–Gabow–Somenzi) stays unbuilt — the closure already answers the class it would target.
